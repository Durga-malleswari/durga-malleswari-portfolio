# Durga Malleswari — Portfolio

A responsive portfolio website for Aadabala Durga Malleswari, B.Tech AI & ML student.

## Run locally

No build tools are required.

1. Keep the folder structure unchanged.
2. Open `index.html` in a browser.
3. For the smoothest local experience, use VS Code + Live Server.

## Files

- `index.html` — page content and sections
- `style.css` — responsive design, animations, dark/light theme
- `script.js` — theme toggle, mobile menu, scroll progress and reveal animations
- `assets/profile.png` — profile photo supplied by Durga
- `assets/resume.pdf` — supplied resume

## Updating the Resume
1. Export your latest resume as a PDF.
2. Rename it exactly to `resume.pdf`.
3. Open the `assets` folder.
4. Replace the existing `resume.pdf` with your new file.
5. Keep the filename `resume.pdf` so both the **Resume** button and **View Resume** button continue to work.
